名词速查

反编译移植
把游戏机器码还原成可读源码，再编译到 PC。可深度改造，周期最长。
静态重编译
把原机器码自动翻译成 C/C++ 直接编译成 PC 程序（如 N64Recomp、XenonRecomp）。
原生重写
参考原版逻辑重写引擎或移植层，不追求逐字节一致。
仅反编译
源码已还原，但还没有可直接游玩的 PC 版本。
线索 · 跟进中
早期研究或通用工具，暂不能正常游玩，收录以便持续跟进（如血源、PS3/PS5 移植工具）。

可玩性怎么核查

不只看作者自述，而是结合社区实际体验（Reddit、论坛、视频、项目 Issue 等）给出结论，并附来源与核查日期；尚未核查的标「未核实」。

✓ 可通关
社区已有完整通关的反馈。
◕ 基本可玩
主线能玩，存在少量问题。
◑ 部分可玩
能进游戏，但崩溃多或内容不全。
✕ 暂不可玩
目前无法正常游玩。

AI 参与度怎么标

AI 主导
作者声明或提交记录显示主要由 AI 编写。进度飞快，但稳定性和长期维护需自行判断。
允许辅助
项目接受 AI 辅助的提交，核心由人工把关。
纯人工
未使用或明确禁止生成式 AI。

收录原则

  • 只收录需要玩家自备正版游戏文件的项目；打包分发版权素材、「打开即玩」的不收录。
  • 本站不提供任何 ROM / ISO / 游戏文件下载。
  • 星数、更新时间、最新版本、支持的平台每周由 GitHub Actions 自动抓取（平台根据 Release 文件名识别）。
  • 游戏封面来自英文维基百科对应词条（直接引用维基图片地址），版权归原厂商所有；没有词条图片的使用自动生成封面。
  • 标「待核实」的链接会跳转到 GitHub 搜索，欢迎提交正确地址。
